# Supply-Chain-KPI-Dashboard
Built an end-to-end Supply Chain KPI Dashboard in Power BI to track Fill Rate, OTIF, Lead Time, Procurement Cost, and Backorder metrics. Developed interactive visualizations and KPI monitoring capabilities to support supply chain performance analysis and operational decision-making.


This dashboard analyzes critical supply chain performance metrics such as Fill Rate, OTIF (On-Time In-Full), Lead Time, Procurement Cost, and Backorders. It provides operational visibility for supply chain managers to improve service levels and procurement efficiency.
